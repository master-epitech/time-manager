# Maquettes Time Manager · charte Lilas Pro

Version du 26/10/2026, préparée par Anthony (missions 04 et 05 · Front).

## Ouvrir les maquettes
Double-cliquez sur **index.html** : la liste des écrans s'ouvre dans le navigateur.
Les écrans sont reliés entre eux (menu, tuiles, boutons). Le menu de gauche est réduit par défaut ; le bouton sous le logo l'agrandit, et le choix est conservé d'une page à l'autre.
Une connexion Internet est utile pour charger les polices (Lexend, JetBrains Mono).

## Contenu
- `index.html` : sommaire
- `ecrans/` : la charte + 15 écrans
- `maquettes-figma.zip` : les mêmes écrans à largeurs fixes, pour l'import dans Figma (plugin html.to.design, onglet File)

## Nouveautés du 26/10

## Charte Lilas Pro (résumé)
- Marque : lilas #6B4FBB
- Code couleur par domaine, toujours avec la même icône : Temps et pointage = lilas (horloge) · Congés = framboise #A83266 (soleil) · Télétravail = sarcelle #0F766E (maison) · Anomalies = corail #B93A22 (triangle) · Demandes et validation = ardoise #4B5563 (document)
- Neutres : encre #2A2238 · gris #574D6B · fond #F4F1FA · bordure #CFC4E4
- Polices : Lexend (textes), JetBrains Mono (heures et durées)
- Accessibilité : contrastes WCAG AA, statut jamais signalé par la seule couleur, pas de rouge/vert, cibles ≥ 44 px
